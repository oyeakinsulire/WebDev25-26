# Web Development Portfolio
This repository documents the weekly creative and technical progression for the WebDev 25-26 module. The project is organized into a dual-themed architecture (Dark and Light modes), showcasing a range of skills from basic HTML structure to advanced JavaScript interaction and generative design.

# Project Structure
The root directory is organized as follows to manage global assets and theme-specific implementations:
Portfolio/

Assets/: Contains global visual resources, including logos (B-Logo.png, W-Logo.png) and subject-specific imagery for both light and dark themes.

DarkMode/: Theme-specific source code and pages designed for dark mode aesthetics, including: about/, home/, menu/, and work/ sections.

LightMode/: Theme-specific source code and pages designed for high-visibility light mode aesthetics, paralleling the DarkMode structure.

# Weekly Progress Summary
The coded components of this portfolio are tracked through a structured weekly versioning system:

Week 01: Initial introduction to web development and environment setup.

Week 02: Exploration of Hyperlinks and non-linear navigation as an artistic tool.

Week 03: Creation of a Self Portrait using web technologies.

Week 04 & 05 - Drafts of Portfolio design.

Week 06: Implementation of the Abstract Clock Design and Typewriter Effect, utilizing real-time JavaScript Date() functions and dynamic CSS gradients.

Week 08: The HTML Form Study, reimagining standard inputs like sliders ("Control the Chaos"), checkboxes, and radio buttons as generative visual elements.

Week 09: Development of a Scrollytelling project, focusing on narrative-driven interactions triggered by user scroll behavior.

Week 10: Final Website Design

Week 11: Creation of 3d shape with three.js that rotates continously
