# Web Development Portfolio Structure

This repository contains the weekly progress and projects for the WebDev 25-26 module. While some design-heavy weeks are hosted on Figma, the following folders represent the coded and uploaded components of the portfolio:

Folder Directory
Week01/: Initial setup and introduction to web fundamentals.

Week02/: Exercises focusing on Hyperlinks and non-linear site navigation.

Week03/: Implementation of the Self Portrait project, exploring personal identity through code.

Week06/: Contains JavaScript-driven work, specifically the Typewriter Effect and the Abstract Clock Design (using real-time Date functions and gradients).

Week08/: The HTML Form Study, utilizing input elements (sliders, checkboxes, buttons) as expressive visual components rather than standard data entry tools.

Week09/scrollytelling: A project exploring scrollytelling, focusing on narrative progression triggered by user scroll behavior.
